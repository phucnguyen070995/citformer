# CiTFormer

Code and stored results for the master's thesis *Dự báo chuỗi thời gian đa biến với Transformer đảo
chiều và phân cụm kép* (Multivariate Time Series Forecasting with Inverted Transformer and Dual
Clustering), Ho Chi Minh City University of Technology (HCMUT), 2026.

CiTFormer (Clustered inverted Transformer) is a multivariate forecaster built on iTransformer. As in
iTransformer, each variable's input window is embedded as one token, but instead of attending over all
C variable tokens, CiTFormer gathers them into K cluster tokens with a learnable soft cluster matrix,
applies self-attention among the K cluster tokens, and scatters the result back to the variables. The
cluster matrix is initialised from groups of co-moving variables found in the correlation matrix, and K
is chosen from its eigen-spectrum. The repository contains the model, the re-implemented baselines
(iTransformer, DUET, DLinear, ARIMA, ETS, LSTM, N-HiTS, Naive), the experiment and analysis scripts, and
the raw JSON results from which every result table of the thesis is generated.

## Method

1. **Number of clusters.** K\* is the smallest k such that the k largest eigenvalues of the C×C
   correlation matrix explain at least 90% of the total variance; the model uses K = max(3, K\*).
2. **Cluster matrix.** W = softmax(Θ) with Θ ∈ R^{C×K} and the softmax taken over variables, so each
   column of W is a weighted average of the C variables. Θ is initialised by PCA + k-means: each variable
   is represented by its loadings on the top-K eigenvectors of the training-split correlation matrix
   (scaled by sqrt(eigenvalue), row-normalised), k-means assigns it to one of K groups, and Θ is α = 2 on
   the variable's own group and 0 elsewhere (`spectral_cluster_init` in `citformer/models/citformer.py`).
   When K\* = 1 (Solar) Θ is initialised randomly.
3. **Gather → attend → scatter.** With variable tokens X ∈ R^{C×d}: cluster tokens Z = WᵀX (plus a
   learnable cluster embedding), a 2-layer Transformer encoder over the K cluster tokens, then
   X ← X + WZ, a per-variable FFN and a linear head to the H-step forecast. Attention costs O(K²)
   instead of O(C²).
4. **Final model (v4).** Pre-norm residual blocks and per-window normalisation (RevIN without affine
   parameters) of the input, de-normalised at the output.

Development stages evaluated in the thesis:

| Config | Change |
|---|---|
| `v1` | random init of Θ, post-norm blocks |
| `v2_emb` | v1 + cluster embedding |
| `v2` | v2_emb + spectral init (α = 2) |
| `v3_rand` | v1 with pre-norm blocks (control for v3) |
| `v3` | v2 with pre-norm blocks |
| `v3_revin` | v3 + per-window normalisation |
| `v4` | v3_revin; random init when K\* = 1 (final model) |

## Installation

Python 3.12; `requirements.txt` pins the versions used for the thesis.

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
pytest
```

All commands below are run from the repository root.

## Data

The eight datasets are public and are not redistributed here. Put them in `data/` (any
sub-directory; `.gz` files are accepted) or point the scripts to another directory with `--data-dir` or
the `CITFORMER_DATA` environment variable. Download links, expected file names and checksums are in
[data/README.md](data/README.md).

| Dataset | File | C | Rows | Step | L → H | Source |
|---|---|---|---|---|---|---|
| ETTh1 | `ETTh1.csv` | 7 | 17,420 | 1 h | 96 → 96 | ETDataset (Zhou et al., 2021) |
| ETTm1 | `ETTm1.csv` | 7 | 69,680 | 15 min | 96 → 96 | ETDataset (Zhou et al., 2021) |
| Exchange | `exchange_rate.csv` | 8 | 7,588 | 1 day | 96 → 96 | LSTNet (Lai et al., 2018) |
| Weather | `weather.csv` | 21 | 52,696 | 10 min | 96 → 96 | Autoformer (Wu et al., 2021); MPI-BGC Jena |
| Covid | `covid.csv` | 55 | 335 | 1 day | 14 → 7 | FourierGNN / FreTS (Yi et al., 2023); JHU CSSE |
| Solar | `solar_AL.txt[.gz]` | 137 | 52,560 | 10 min | 96 → 96 | LSTNet (Lai et al., 2018) |
| ECL | `electricity.csv` | 321 | 26,304 | 1 h | 96 → 96 | LSTNet (Lai et al., 2018) |
| Traffic | `traffic.csv` | 862 | 17,544 | 1 h | 96 → 96 | LSTNet (Lai et al., 2018) |

Common protocol for every model: chronological 70/10/20 train/validation/test split, standardisation
with training-split statistics, sliding windows with stride 1, and the last column (`OT` where present)
as the forecasting target. All models are scored on the first 1000 test windows (Covid has only 48),
with MAE and RMSE in the original units of the target. In `weather.csv` the value -9999 is a
missing-value code (81 cells); these cells are linearly interpolated when the file is read
(`citformer/data.py`), after which K\* = 6 for Weather.

## Reproducing the thesis

### Tables from the stored results

```bash
python analysis/make_tables.py        # -> results/tables/*_rows.tex, results/figures/fig_ksweep.png
```

| Output | Thesis table (Chapter 5) |
|---|---|
| `stage1_rows.tex` | stage 1, no per-window normalisation: iTransformer, DUET without RevIN, CiTFormer v1/v2 (`tab:stage1`) |
| `stage2_rows.tex` | stage 2, pre-norm CiTFormer v3 and its MAE change w.r.t. v2 (`tab:stage2`) |
| `revin_effect_rows.tex` | stage 3, MAE change when per-window normalisation is switched on (`tab:revin_effect`) |
| `seeds_rows.tex` | stage 3, main comparison over 3 seeds: iTransformer, DUET, CiTFormer-v4, s/epoch (`tab:seeds`) |
| `mae_table_rows.tex`, `rmse_table_rows.tex` | MAE / RMSE of all univariate and multivariate models (`tab:mae`, `tab:rmse`) |
| `v1v2_rows.tex` | random vs. spectral init: v1, v2, v3, v3_rand and the centred cluster cosine (`tab:v1v2`) |
| `ksweep_rows.tex`, `fig_ksweep.png` | sensitivity to K (`tab:ksweep`) |

`make_tables.py` reads every `*.json` in `results/multivariate/` and `results/stat_baselines/`. Weather
rows are taken only from `results/weather_clean/`; the earlier Weather rows in `results/multivariate/`
(file read without interpolating -9999, K = 8) are ignored. The Naive results (`results/naive/`) are
not part of these tables.

### Re-running the experiments

Each script writes one row per run to its JSON file; `run_multivariate.py` and
`run_stat_baselines.py` skip runs already present in the file, so an interrupted job can be resumed.
Training defaults: seeds 0, 1, 2; at most 200 epochs; early stopping with patience 20; Adam (lr 1e-3,
weight decay 1e-5) with ReduceLROnPlateau (factor 0.5, patience 5).

```bash
SMALL="ETTh1 ETTm1 Exchange Weather Covid"   # CPU
LARGE="Solar ECL Traffic"                    # GPU

# Stages 1-2 and the initialisation study (stage1, stage2, v1v2)
python experiments/run_multivariate.py --datasets $SMALL \
    --configs iTransformer DUET_norevin v1 v2_emb v2 v3_rand v3 --out results/multivariate/stages12.json

# Stage 3 (revin_effect, seeds, mae, rmse)
python experiments/run_multivariate.py --datasets $SMALL \
    --configs iTransformer_revin DUET v3_revin v4 --out results/multivariate/stage3.json

# Sensitivity to K: K*/2, 2K*, sqrt(C) (ksweep)
python experiments/run_multivariate.py --datasets $SMALL --configs v3 --ks sweep \
    --out results/multivariate/ksweep.json

# Univariate baselines (mae, rmse)
python experiments/run_stat_baselines.py --out results/stat_baselines/stat_1000.json
python experiments/run_uv_deep.py --datasets Weather --out results/weather_clean/weather_uv_deep.json
python experiments/run_naive.py --out results/naive/naive.json
```

Use `$LARGE` instead of `$SMALL` for Solar, ECL and Traffic. A quick end-to-end check (1 epoch, 256
training windows):

```bash
python experiments/run_multivariate.py --datasets ETTh1 --configs v4 --seeds 0 --epochs 1 \
    --max-train 256 --out smoke.json
```

## Notes on the stored results

- Config names in the JSON files are those of `experiments/run_multivariate.py`; `K` is `null` for
  models without clusters.
- `kaggle_v4_ablation.json` and `local_v4_ablation.json` also contain two exploratory configs that are
  not used in the thesis and no longer exist in the code: `v3_auto`, and an earlier `v4` whose init
  strength was set per cluster. `make_tables.py` relabels the latter `v4_autoalpha`. The final v4 rows
  are taken from `v3_revin` when K\* > 1 and from `v4_autoalpha` for Solar (K\* = 1, random init, so the
  init strength is unused); both are the same computation as the final v4.
- The K values in `citformer/data.py` were computed on the full series (`k_star_full` in
  `results/ida/kstar_train_vs_full.csv`, which also lists the training-split values). The spectral
  initialisation itself uses only the training split.
- LSTM and N-HiTS values other than Weather are single-seed results of the original per-dataset runs
  (same architectures as `experiments/run_uv_deep.py`) and are written directly in `make_tables.py`.
  The timings in `timing_figure.py` come from a separate timing run on GPU.

## Hardware

- ETTh1, ETTm1, Exchange, Weather, Covid: CPU of a personal computer (`results/multivariate/local_*.json`,
  `results/weather_clean/`). Training times on these datasets are not used for speed comparisons.
- Solar, ECL, Traffic: Kaggle, 2× NVIDIA T4, same scripts (`results/multivariate/kaggle_*.json`). With
  several GPUs the training loop uses `nn.DataParallel`.
- Small differences across machines and library versions are expected from non-deterministic
  floating-point arithmetic.
